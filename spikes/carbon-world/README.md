# CARBON-WORLD PROTOTYPE (spike) — جهانِ کربنیِ قطعی

> 🧪 **کدِ آزمایشیِ دورریختنی** — هدفِ اصلیِ مرحلهٔ ۱: جهانِ رویه‌ای که حیات در آن زندگی کند.

## چه چیزی می‌سازد / What it builds
از یک `seed`، یک سیارهٔ کامل تولید می‌کند — **تماماً عددِ صحیح/Q16.16، بدونِ float** → بازتولیدپذیرِ بیت‌به‌بیت و native==wasm.
- **ارتفاع:** نوفهٔ مقداریِ fBm (۵ اوکتاو) + بسطِ کنتراست → قاره/اقیانوس.
- **دما:** بندِ عرضِ جغرافیایی (گرم در استوا، سرد در قطب) منهای افتِ ارتفاعی.
- **رطوبت:** میدانِ fBmِ دوم.
- **زیست‌بوم:** دسته‌بندیِ سبکِ ویتاکر از (ارتفاع، دما، رطوبت) → ۱۳ زیست‌بوم (اقیانوسِ ژرف/اقیانوس/ساحل/کویر/ساوانا/علفزار/بوته‌زار/جنگلِ معتدل/جنگلِ بارانی/تایگا/توندرا/صخره/برف).

## اجرا / Run
```bash
rustc -O world.rs -o world
./world <seed> [nomap]      # نقشهٔ ASCII + JSON (هیستوگرام، land%، اثرانگشت)
```

## مرورگر / Browser viewer
فایلِ **`web/carbon-world.html`** را در هر مرورگری باز کنید (خودبسنده، wasmِ ۱.۷KB جاسازی‌شده، **بدونِ سرور**). دکمهٔ «🎲 سیارهٔ نو»، ورودیِ seed، و سایهٔ ارتفاع.
- ساخت: `rustc --target wasm32-unknown-unknown -C opt-level=z -C lto=fat -C panic=abort -C strip=symbols world_wasm.rs -o web/world.wasm` → `node web/build.js`.

## شواهد / Evidence (VERIFIED ✅)
- **قطعیت + native==wasm:** اثرانگشتِ seed=16 → `7541945590315730226` در native، wasm، و wasmِ جاسازی‌شده در HTML **یکسان** (`node web/verify.js <fp>`).
- **تنوع:** seedهای مختلف سیاره‌های متفاوت می‌دهند (seed 7 = ابرقارهٔ سرد با هر ۱۳ زیست‌بوم؛ seed 16 = اقیانوس‌محور). نمونه: `MAP.txt`.

## صداقت / Honesty
- ⚠️ **این یک «اختراع» نیست** — تولیدِ رویه‌ای (نوفهٔ Perlin/value، fBm، زیست‌بومِ ویتاکر) پیشینهٔ گستردهٔ شناخته‌شده دارد. این **زیرساخت** است. بودجهٔ نوآوری به **یکپارچه‌سازیِ آینده** (حیات + جهان + باورِ نوظهور) موکول می‌شود. (INV-0010 با تازگیِ NONE ثبت شد.)
- ❓ هنوز رودخانه/جریانِ اقیانوسی/اقلیمِ زیرگرمسیری (کویرهای ۳۰°) نیست؛ حیات هنوز روی جهان قرار نگرفته — کارِ بعد.

فایل‌ها: `carbon_core.rs` هستهٔ مشترکِ no_std · `world.rs` native · `world_wasm.rs` wasm · `web/` بیننده+راستی‌آزما.
