# NEURAL-LIFE PROTOTYPE (spike) — حیاتِ عصبیِ قطعی

> 🧪 **کدِ آزمایشیِ دورریختنی** — کدِ نهاییِ بازی نیست. اثباتِ عملیِ **INV-0004** روی هستهٔ قطعیِ اثبات‌شده (SPIKE-COMPARE).

## چه چیزی را نشان می‌دهد / What it demonstrates
موجوداتِ **عصبیِ fixed-pointِ قطعی** با **سائقِ زیستی** (انرژی/گرسنگی) که در یک جهانِ کوچکِ غذا زندگی می‌کنند و **هنگامِ تولیدِمثل تکامل** می‌یابند (وزن‌ها + جهشِ قطعی). هیچ floatای در شبیه‌سازی نیست → بازتولیدپذیرِ بیت‌به‌بیت.

- مغز: MLP کوچک fixed-point (۴ ورودی → ۶ نهان با ReLU → ۵ کنش)، تصمیم با argmax.
- ادراک: جهتِ نزدیک‌ترین غذا در شعاع + انرژیِ نرمال‌شده.
- سائق: هر تیک انرژی کم می‌شود؛ خوردن آن را زیاد می‌کند؛ صفر = مرگ؛ بالا = تولیدِمثل (فرزند با وزنِ والد + جهش).
- جهان: شبکهٔ ۲۸×۲۸ چنبره‌ای (toroidal)، غذا به‌صورتِ قطعی می‌روید.

## اجرا / Run
```bash
rustc -O life.rs -o life
./life <ticks> <seed> [snap]
./life 500 12345          # نتیجهٔ JSON
./life 500 12345 snap     # + اسکرین‌شاتِ ASCII (tick 0, نیمه، پایان)
```
