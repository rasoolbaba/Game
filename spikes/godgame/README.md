# GOD-GAME LOOP (spike) — حلقهٔ بازیِ خدا

> 🧪 کدِ آزمایشیِ دورریختنی. اولین **بازیِ واقعی**: نفوذِ غیرمستقیمِ خدا روی نوسفر (حیات+جهان+باور).

## حلقه / The loop
بازیکن (خدا) **مستقیم فرمان نمی‌دهد** — الهام می‌فرستد و مردمانِ عصبی **آزادانه** واکنش می‌دهند:
- **📜 آیه (verse):** ایمانِ تو را در یک ناحیه می‌کارد (نیمه‌نیرومند → مردم ممکن است با هم‌نوایی بازگردند = ارادهٔ آزاد).
- **🌾 خوراک (bounty):** ضیافت (پُرکردنِ غذا) → زندگی شکوفا/جذب می‌شود.
- **🔥 گرما (warm):** معجزهٔ خفیف (افزایشِ دما) → بقا در سرما آسان‌تر.
- **🙏 نیایش (devotion):** قدرتِ تو؛ از **مؤمنان** (هم‌سو با ایمانت) می‌جوشد و خرجِ آیه/معجزه می‌شود. → حلقهٔ بازخوردِ کلاسیکِ god-game.

## ⚠️ صداقت (ADR-0003) / Honesty
این یک **ژانرِ شناخته‌شده** است (الهام‌گرفته از Black & White؛ نیایش‌محور)، **نه اختراعِ نو** — و چون هویتِ ما دیگر «اختراع در هر گام» نیست، صادقانه همین را می‌گوییم. ارزشِ آن: **اصیل، باکیفیت، و کاملاً قطعیِ خودمان**.

## شواهد / Evidence (VERIFIED ✅)
- **native==wasm با کنش‌های تعاملی:** اسکریپتِ ثابتِ آیه/معجزه روی native و wasm اثرانگشتِ یکسان داد: `10683066695076585027`. یعنی کنش‌های خدا = رویدادهای قطعیِ **P2P-syncable** (سازگار با معماری).
- wasmِ ۷.۷KB؛ بینندهٔ خودبسندهٔ ۱۷KB.

## اجرا / Play
فایلِ **`web/godgame.html`** را در مرورگر باز کنید: ابزار را برگزینید، روی نقشه کلیک کنید؛ حلقهٔ سفیدِ دورِ موجودات = مؤمنانِ شما. «ایمانِ تو» (رنگ) را عوض کنید تا کیشِ دیگری را رهبری کنید.
```bash
rustc -O god.rs -o god && ./god <world> <sim>     # اجرای اسکریپتیِ native (آزمونِ قطعیت)
rustc --target wasm32-unknown-unknown -C opt-level=z -C lto=fat -C panic=abort -C strip=symbols god_wasm.rs -o web/god.wasm && node web/build.js
```
