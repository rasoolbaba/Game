# SPIKE-COMPARE — نتایج / Results

**تاریخ:** 2026-06-04 · **ماشین:** همین کانتینرِ نشست (تک‌هسته، بدون GPU) · **وضعیت:** شواهدِ خام، بازتولیدپذیر.
**تابعِ:** [`ADR-0001`](../../docs/decisions/ADR-0001-tech-stack.md) · پرسشِ تیمِ قرمز (قطعیت) و دروازهٔ کامل‌بودن.

> ⚠️ این یک **میکروبنچمارک** است: شبکهٔ کوچک (۸-۱۶-۸)، تک‌نخ، بدون GPU، بدون سامانه‌های واقعیِ بازی. اعداد **نشان‌دهنده‌اند، نه پیش‌بینی‌کننده** برای بازیِ کامل (`ASSUMED ⚠️`).

---

## ۱. روش (یکسان در هر چهار پیاده‌سازی) / Methodology
- **حساب:** Q16.16 fixed-point روی صحیحِ ۶۴-بیتی. `mul = (a*b)>>16` (شیفتِ حسابی).
- **tanh:** جدولِ جست‌وجوی صحیح (۵۱۳ نقطه روی [-8,8]) + درون‌یابیِ خطیِ صحیح. تنها استفاده از float، **زمانِ ساخت** برای ضرب‌سکهٔ ثابت‌هاست (`gen.mjs`) — هرگز در زمانِ اجرا.
- **وزن‌ها:** PRNG صحیحِ xorshift64 با seed ثابت (یکسان در همه).
- **بار:** یک MLPِ بازگشتی (۸→۱۶ با tanh →۸ با tanh)، خروجی به ورودیِ تیکِ بعد بازخورد می‌شود؛ T تیک.
- **اثرانگشت:** هشِ ۶۴-بیتیِ FNV-1a روی **همهٔ** خروجی‌های هر تیک (`acc`). قطعیت = یکسان‌بودنِ `acc` در همه.
- **پیاده‌سازی‌ها:** `js-bigint` (Node)، `rust-native` (rustc -O)، `assemblyscript-wasm` (asc -O3, stub)، `rust-wasm` (rustc --target wasm32-unknown-unknown).

## ۲. دروازهٔ قطعیت / Determinism gate — **PASS ✅**
هر چهار پیاده‌سازی، اثرانگشتِ **بیت‌به‌بیت یکسان** تولید کردند:

| T | acc (هر چهار یکسان) |
|---|---|
| 200,000 | `10976031671373174120` |
| 1,000,000 | `6467199680628183720` |

> یعنی fixed-pointِ صحیح، **مستقل از زبان و رانتایم**، قطعی است. بازتولید: `./run-all.sh 1000000` (با assert).

## ۳. کارایی / Performance @ T=1,000,000

| پیاده‌سازی | ms | ticks/sec | نسبت به rust-native |
|---|---:|---:|---:|
| **rust-native** | 139 | ۷٬۱۸۰٬۱۰۲ | **۱.۰۰×** (مرجع) |
| **rust→wasm** | 271 | ۳٬۶۹۱٬۷۲۱ | ~۱.۹× کندتر |
| **assemblyscript→wasm** | 1٬878 | ۵۳۲٬۵۳۹ | ~۱۳.۵× کندتر |
| **js-bigint** | 11٬092 | ۹۰٬۱۵۴ | ~۸۰× کندتر |

- **rust→wasm ≈ ۷× سریع‌تر از assemblyscript→wasm** برای این بارِ i64 (کیفیتِ codegenِ LLVM در برابر binaryen).
- **js-bigint ~۴۱× کندتر از rust→wasm**: چون قطعیتِ صحیحِ ۶۴-بیتی در JS نیازمندِ BigInt است (Number = float64 و برای صحیحِ دقیقِ ۶۴-بیتی ناکافی).

## ۴. اندازهٔ باینریِ wasm (مهم برای وب) / WASM size
| پیاده‌سازی | اندازه |
|---|---:|
| assemblyscript→wasm | **۵٬۶۶۲ بایت** (~۵.۵KiB) |
| rust→wasm (cdylib, std, بهینه‌نشده برای اندازه) | **۱٬۳۵۶٬۴۰۳ بایت** (~۱.۳MiB) |

> ⚠️ `rust→wasm` این‌جا برای **اندازه** بهینه نشده. کاهش با `no_std` + `opt-level=z` + `wasm-opt` ممکن است (`ASSUMED ⚠️`، اسپایکِ بعدی). AssemblyScript ذاتاً wasmِ بسیار کوچک می‌دهد.

## ۵. یافته‌های صادقانه / Honest findings
1. ✅ **قطعیت، انحصاریِ Rust نیست.** هر چهار، قطعی‌اند. پس «قطعیت» به‌تنهایی Rust را الزامی نمی‌کند — این، تصحیحِ صادقانهٔ توجیهِ اولیه است.
2. ✅ **Rust برای کارایی برنده است** (~۷× از AS، ~۴۱× از JS در این هستهٔ داغ). توجیهِ درستِ Rust = **کارایی + ایمنیِ حافظه + «یک هسته، native و وب»**، نه افسانهٔ «فقط Rust قطعی است».
3. ⚖️ **AssemblyScript** جذاب است: قطعی، wasmِ کوچک، زنجیرهٔ ساده‌تر — اما ~۷× کندتر و فاقدِ اکوسیستم/ایمنیِ Rust.
4. ⚖️ **JS خالص** برای منطقِ غیرداغ عالی است، اما برای هستهٔ شبیه‌سازیِ ۶۴-بیتی به‌خاطرِ BigInt گران است.

## ۶. هشدارها / Caveats (آنچه این اسپایک اثبات نکرد)
- ❓ **قطعیتِ میان‌ماشینی/میان‌OS:** این‌جا میان‌**زبان/رانتایم** روی **یک ماشین** آزمودیم. صحیح‌محوربودن، استقلال از سکو را **از نظر تئوری** تضمین می‌کند، اما آزمونِ روی سخت‌افزار/OS متفاوت `ASSUMED ⚠️` باقی است.
- ❓ **توابعِ بیشتر:** فقط `tanh` (LUT) آزموده شد. `exp/softmax` و غیره باید صحیح‌سازی و **در SPIKE-0 دوباره اثبات** شوند.
- ❓ **مقیاس واقعی:** شبکهٔ کوچک، تک‌نخ، بدون GPU. کارایی در بازیِ کامل `UNKNOWN ❓`.
- ❓ **اندازهٔ wasmِ Rust** نیازمندِ بهینه‌سازیِ جداگانه است.

## ۷. بازتولید / Reproduce
```bash
cd spikes/spike-compare
node gen.mjs                                   # mint shared LUT
rustc -O rust/sim.rs -o rust/sim               # native rust
rustc -O --target wasm32-unknown-unknown --crate-type cdylib -C panic=abort \
      rust/sim_wasm.rs -o rust/sim_wasm.wasm   # rust→wasm
( cd as && npm i -D assemblyscript && npm run asbuild )   # as→wasm
./run-all.sh 1000000                            # runs all 4 + asserts identical acc
```
