# NOOSPHERE PROTOTYPE (spike) — حیات + باورِ نوظهور / life + emergent belief

> 🧪 کدِ آزمایشیِ دورریختنی. یکپارچه‌سازیِ INV-0004 (حیاتِ عصبی) + جهانِ کربنی + لایهٔ باور.

## چه چیزی است / What it is
موجوداتِ عصبیِ قطعی در زیست‌بوم‌های جهان (غذا/دما مهم‌اند) زندگی می‌کنند و هرکدام یک **بردارِ باورِ ۳بُعدی** دارند که هر تیک به‌روز می‌شود:
- **هم‌نوایی (قوی):** کشش به میانگینِ باورِ همسایه‌ها. (= مدلِ DeGroot/Hegselmann–Krause)
- **اثرِ زیست‌بوم (ضعیف، β):** کششِ خفیف به کهن‌الگوی باورِ زیست‌بوم.
- **هم‌بستگی به‌مثابهٔ بقا:** هم‌فکریِ محلی → پاداشِ کوچکِ انرژی. (= برچسب‌های فرهنگیِ Sugarscape / گزینشِ گروهیِ فرهنگی)
- باور هنگامِ تولیدِمثل به ارث می‌رسد. رنگِ موجود = باورش.

## ⚠️ صداقت (مهم‌ترین بخش) / Honesty
دو گروهِ مستقل (تحقیق + تیمِ قرمز) ارزیابی کردند. نتیجه:

1. **این اختراع نیست.** مکانیک ~۹۰٪ پیشینهٔ شناخته‌شده است: مدلِ پخشِ فرهنگِ **Axelrod (1997)** (همان هدفِ «مناطقِ فرهنگیِ مجزا که بین جمعیت‌های جدا واگرا می‌شوند» را قبلاً تولید کرده)، دینامیکِ عقیدهٔ **Hegselmann–Krause/Deffuant**، برچسب‌های **Sugarscape**، و بازی‌های منتشرشده (**RimWorld Ideology، Dwarf Fortress، Black&White، Sims Medieval**).
2. **برچسبِ «جاذبِ عصبی» حذف شد.** مکانیکِ واقعی **هم‌نواییِ خطی** است، نه شبکهٔ Hopfield. نگه‌داشتنِ آن نام = ادعای کاذب (نقضِ C4). نامِ صادقانه: **«میدانِ هم‌نواییِ باورِ جمعی»**.
3. **ادعای «دینِ نوظهور» از دروازهٔ ابطالِ خودمان رد نشد** (پایین را ببینید).

تنها نوآوریِ احتمالی (همه `ASSUMED ⚠️`، اثبات‌نشده): *یکپارچه‌سازی* روی بسترِ عصبیِ قطعیِ P2P + اثرِ زیست‌بومِ رویه‌ای. → **INV-0005 در DISCLOSED می‌ماند؛ هیچ تازگی‌ای ادعا نمی‌شود.**

## اجرا / Run & view
```bash
rustc -O noo.rs -o noo && ./noo <world_seed> <sim_seed> <β:0|1> <ticks> [map]
rustc --target wasm32-unknown-unknown -C opt-level=z -C lto=fat -C panic=abort -C strip=symbols noo_wasm.rs -o web/noo.wasm && node web/build.js
node web/tests.js <native_fp>     # آزمون‌های ابطال
```
فایلِ **`web/noosphere.html`** را باز کنید. «🎲 موجوداتِ نو (همان جهان)» را چند بار بزنید تا **مسیر‌وابستگی** را زنده ببینید؛ تیکِ «اثرِ زیست‌بوم» را خاموش کنید تا ظهورِ خالص (β=۰) را ببینید.
