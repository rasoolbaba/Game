# 04 — پروتکلِ طوفان فکری / Brainstorm Protocol 🌩️

**نسخه / Version:** 1.0.0 · **تابعِ:** [`00-INTEGRITY-PROTOCOL.md`](00-INTEGRITY-PROTOCOL.md) (مادهٔ ۵)

> هر تصمیمِ بزرگ باید از یک طوفان فکریِ ثبت‌شده بگذرد. هدف: زاویه‌های متفاوت، نقدِ متقابل، و خروجیِ شاهد‌محور — نه هم‌اندیشیِ کور.

---

## ۱. شش فازِ یک جلسه / Six phases

1. **فریم / Frame** (رهبر): مسئله چیست؟ معیارهای موفقیت؟ محدودیت‌ها؟ این یک تصمیمِ بنیادین است یا عادی؟
2. **واگرایی / Diverge** (۴ گروه، **موازی**): هر گروه گزینه‌ها را با **زاویهٔ نوآوری** ارائه می‌دهد. کمیّت بر کیفیت مقدم است؛ قضاوت ممنوع.
3. **هم‌گرایی / Converge** (رهبر + گروه‌های مرتبط): خوشه‌بندی، حذفِ تکراری، کوتاه‌لیست با trade-offها.
4. **تیمِ قرمز / Red-Team** (گروه ۳، **اجباری**): مخالفتِ مستند، حالت‌های شکست، آزمونِ تازگی (مادهٔ ۳). «نبودِ مخالفت = پرچمِ زرد».
5. **تصمیم / Decide** (رهبر، جسور): انتخاب + دلیلِ شفاف + آنچه عمداً رد شد.
6. **ثبت / Record:** نوشتنِ **ADR**، به‌روزرسانیِ **حافظهٔ شورا**، و در صورت لزوم ثبت در **دفتر اختراعات/تجربیات**؛ سپس **گذرِ ممیز**.

---

## ۲. قواعدِ ضدِّ groupthink / Anti-groupthink rules
- تیمِ منتقد **موظف** به ارائهٔ دستِ‌کم دو مخالفتِ مستند است.
- هر گروه باید **یک ایدهٔ پرریسک/جسورانه** هم بیاورد (نه فقط امن).
- رهبر آخرین کسی است که موضع می‌گیرد تا لنگرگاهِ (anchoring) زودهنگام رخ ندهد.
- هر ادعای «این بهتر است» باید به یک معیارِ سنجش‌پذیر گره بخورد (مادهٔ ۱).

---

## ۳. قالبِ ثبتِ جلسه / Session record template

```
# BRAINSTORM-<شماره> — <عنوان> — <YYYY-MM-DD>
## فریم: <مسئله، معیارها، محدودیت‌ها، بنیادین؟ بله/خیر>
## واگرایی (به‌تفکیکِ گروه):
- 🎨 گرافیک/VFX: <گزینه‌ها + زاویهٔ نوآوری>
- 🧠 هوش/تحقیق: <…>
- 🔬 منتقدان: <…>
- 🌐 شبکه/اقتصاد: <…>
## هم‌گرایی: <کوتاه‌لیست + trade-offها>
## تیمِ قرمز (مخالفت‌های مستند): <۱… ۲…>
## تصمیم: <انتخاب + دلیل + آنچه رد شد>
## خروجی‌ها: ADR-… | INV-… | EXP-… | اسکرین‌شات‌ها
## گذرِ ممیز: PASS ✅ / RED-FLAG 🚩 (لینک به AUDIT-…)
## ارجاع به حاکم؟ بله/خیر
```

---

## ۴. کِی جلسه لازم است / When a brainstorm is required
- انتخابِ زبان/فناوری/معماری.
- هر مکانیکِ کلیدیِ بازی یا تصمیمِ گرافیکیِ هویت‌ساز.
- مدلِ اقتصادی/ارز.
- هر زمان که ممیز یا یک گروه آن را بطلبد.
